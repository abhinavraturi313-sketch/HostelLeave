# Hostel Leave and Complaint Management System
Advanced Internet Programming mini project.

Technologies: Java Servlets, JSP, JDBC, MySQL, Apache Tomcat 11.

## How to run
1. Create the database: import hostel.sql into MySQL (database name: hostel_db).
2. Set your MySQL password in src/main/java/com/hostel/util/DBConnection.java (PASS).
3. Add the MySQL Connector/J jar to WEB-INF/lib.
4. Deploy on Tomcat 11 and open http://localhost:8080/HostelLeave/
